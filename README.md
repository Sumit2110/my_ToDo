A full-stack ToDo application that allows users to create, manage, update, and delete tasks through a simple and user-friendly interface.

Features :
User registration and login
JWT-based authentication
Create, update, and delete tasks
Mark tasks as completed
Task descriptions and management
Responsive React frontend
Node.js and Express backend
MongoDB database

Tech Stack :
Frontend: React, CSS
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT, bcrypt.js
